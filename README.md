# noroloji-takvim

Nöroloji stajı (16 Kasım – 25 Aralık 2026) küçük grup takvimleri. Her dosya bir küçük grubun 6 haftalık programıdır: sabah pratikleri, gözlem rotasyonları, LP, Beyin Cerrahisi rotasyonu, teorik dersler ve sınavlar.

Takvim uygulamasına **abonelik linki** olarak eklenir; program değişince takvim kendiliğinden güncellenir.
